# Modem Packaging Inspection

**An AI-powered computer vision system for automated modem recognition and packaging quality inspection.**

## Overview

This project aims to develop a computer vision system capable of identifying modem devices and verifying the correctness of their placement and arrangement within product packaging.

The project is being developed in collaboration with **Fanap Tech**.

## Project Objectives

The development process is divided into two main stages:

### 1. Modem Recognition (Proof of Concept)

Develop an object detection model capable of recognizing modem devices under different conditions, including:

- Different viewing angles (front, back, side, and top).
- Different orientations and positions.
- Various lighting conditions and backgrounds.

### 2. Packaging Inspection

Extend the recognition system to identify packaging components and verify their presence and correct placement.

## Technology Stack

- Python
- PyTorch
- Ultralytics YOLO
- OpenCV
- NumPy
- CVAT (Data Annotation)
